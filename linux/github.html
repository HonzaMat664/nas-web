	   		Pokud se poškodí Git repozitář, nejjednodušší je nové nahrání nas-web do git hub:

	   		1. Ověření stavu

	   		git fsck --full

	   		🧹 2. Smaž starý Git (poškozený)

	   		cd ~/nas-web
	   		rm -rf .git
	   		Tím odstraníš všechny poškozené objekty.

	   		🆕 3. Vytvoř nový Git repozitář

	   		git init


	   		📦 4. Přidej remote (GitHub)

	   		git remote add origin git@github.com:HonzaMat664/nas-web.git


	   		🧾 5. Přidej všechny soubory

	   		git add .


	   		💾 6. Udělej nový “fresh start” commit

	   		git commit -m "Fresh start - clean import from working directory"


	   		🚀 7. Push na GitHub (hlavní větev)
	   		Nejčastěji dnes GitHub používá main:

	   		git branch -M main
	   		git push --force -u origin main
